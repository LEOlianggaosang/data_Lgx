# 概念
- EMC：Electromagnetic compatibility/电磁兼容性
	- EMC = EMI +EMS
- EMI：Electromagnetic Interference/电磁干扰
	- RE：Radiate Emission/辐射发射
	- CE：Conduct Emisssion/传导发射
	- Harmonic/谐波电流测量
	- Fluctuation and Flicker/电压波动和闪烁测量
- EMS：Electromagnetic Susceptibility/电磁抗扰度
	- RS：Radiate Susceptibility/辐射抗扰度
	- CS：Conduct Susceptibility/传导抗扰度
	- ESD：Electrostatic Discharge/静电放电抗扰度
	- EFT：Electrical Fast Transient/Brust/电快速瞬变脉冲群
	- Surge/浪涌抗扰度
	- *PMS*：ower-frequency magnetic susceptibility/工频磁场抗扰度
	- DIP：Dips/interruptions/电压跌落与短时中断
# 要素
- EMC三要素：干扰源、敏感设备、耦合途径
- 干扰源：限制干扰源的电磁发射
	- 环境噪声：宽频，剧烈
	- 设备噪声
	- 静电放电
- 敏感设备：控制电磁干扰的传播
	- 测试对象
	- 测试设备
- 耦合途径：增强敏感设备的抗干扰能力
	- 传导干扰：沿电源线或信号线及公用地线等传输的电磁干扰
	- 辐射干扰：通过空间传播的电磁干扰
