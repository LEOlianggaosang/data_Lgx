# 华拓
- 蜂鸣
	1. 和旋音驱动开关机
	2. 暂停每60s蜂鸣一次
	3. 开关门蜂鸣一次
	4. 洗涤完成无提示直接关机
- 耗材显示
	1. 全局检测，洗涤不显
		- [ ] 改为：洗涤不检，全局显示
- 开关机显示
	1. 上电全亮1s进入关机状态全熄灭
	2. 开机改为**流水灯显示** %% 新增 %%
	3. 默认程序为强力洗
		- [x] 改为ECO
	4. 电源键、默认程序总时间常亮，菜单键与启停键闪烁
- 新增显示
	- [ ] 进入待机流水灯显示
	- [ ] 自动洗数码管转圈特殊处理
- 休眠处理
	1. 关机无LED显示
	2. 上电全亮无蜂鸣
	3. 开机后无动作15分钟自动关机，按键刷新计时
	4. 洗涤完成直接进入关机
- 特殊模式
	1. 自检一
	2. 自检二
	3. 负载检测模式
	4. 软水等级调节模式
	5. 调试参数显示功能
		- 只在洗涤有效
		- 按键显示规则
		- [ ] 统一开门暂停与按键暂停显示
- 开门处理
	1. 启动延时10s，无关是否按键暂停
	2. 只有开门暂停计时清零，其他时候一直累加到最大值
	3. 负载驱动标志位清零
	4. 强电开关断开继电器供电
	5. 缓存上一个状态：运行/暂停
- 暂停处理
	1. 单独状态
	2. 标志位区别开门，开门后运行键无效
	3. 出入口区别与自动运行
	4. 计数暂停时基走另一分支不判断判断累加与清零
- 时基处理
	1. 一种清零条件/动作新开一种计时
	2. 与工作函数互锁清零
	3. 步骤时间累计与归零
- 结束条件
	1. 查表：时序表格式
	2. 提前结束的步骤
- 工作函数
	1. 主循环中重复进入
	2. 靠时间计数判断
- 倒计时处理
	1. 正常走时：都无延时
	2. 提前结束，就是正常倒计时
	3. 只有温达跳步跳时间：对齐到下一步
	4. 对齐机制：每步更新步骤配时累计作为下限
	5. 不满一分钟步骤凑时间作为配时，无上限判断
		- [ ] 跳步骤增加上限
- 加热处理
	1. 条件：6分钟上升不到3度触发加热故障
	2. 加热步骤不适用于小于6分钟或大于25分钟的步骤
	- 加热故障处理
		1. 触发后本次步骤不再打开加热管
		2. 本次加热步骤变为洗涤25分钟
		3. 下次加热步骤清除
		4. 结束不报警
	- 加热补偿机制
		1. 设定时间内未到达设定温度触发
		2. 本次加热步骤变为洗涤25分钟
		3. 继续加热，25分钟内达到设定温度跳出
		4. 超过25分钟直接跳步骤
	- 加热步骤种类
		1. 定时加热-时间
			- [ ] 无需判断温度，无需处理加热延时与加热故障
		2. 定温加热温达剩洗T45/600
		3. 定温加热温达跳步T56
		4. 保温特殊说明-温度（3度）
- 故障状态处理
	1. 漏水动作：蜂鸣器响30s 然后排水直流量计无动作120s，开门暂停
	2. 洗涤泵动作：洗涤出现溢流再动作120s，开门取消
- 负载驱动
	1. 开门强电关断，标志位清零
	2. 故障关断除非特殊驱动条件
	3. 开门后关门延时启动10s，不占用步骤时间
	4. 启停加热管驱动延时5s， 开门后关门延时启动10s，叠加关门延时启动，占用步骤时间!
