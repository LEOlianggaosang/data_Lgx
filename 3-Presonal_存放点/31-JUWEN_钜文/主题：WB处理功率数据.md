## 初步处理
- 运行过程提炼：交叉验证，口述信息+口述补充+测试数据+时序表
- 时间戳推理：弱化无关更改内容，强调有关更改内容。事件排布，疑问梳理，问题交叉验证确认
- 功率数据表格整理：查重，命名（日期+套数+工位）
- 对照关系参考：
	- 对象：工位 <-> 套数 <-> 对应 `时序表`，工位 <-> `功率数据表格` 对应数据列
	- 模型：`运行记录` 所选程序与功能 <-> `时序表` 分栏与读取区域 + `时序表阅读方式与定义`
	- 特征：`功率特征` 负载、变化规律、持续时间 <-> `时序表` 分栏、读取区域、步骤描述、参数 + `时序表阅读方式与定义`
	- 时间：`时间线` 定位 + `运行记录` 启动时间 <-> `功率数据表格` 锁定对应表格与对应时间段
	- 因果：`时间线` 排列参考，有问题 -> 更新 -> 测试数据 -> 有问题
- 不能认定为现实：
	- 疑问：包括 口述补充 与 更改涉及的笔记 提及，可能不是真正的 `问题` ，需要对照 `时间线` 辅助推理，判断以 `功率数据表格` 与 `时序表` 对照为准
	- 设定时间：口述补充 提及，以所选程序与功能对应 `时序表` 总时间为准
	- 设定结束：口述补充 提及，以 `功率数据表格` 数据为准
	- 异常：`功率数据表格` 对不上的地方，指引我查看实际数据，以我的解释为准

## 运行诊断
