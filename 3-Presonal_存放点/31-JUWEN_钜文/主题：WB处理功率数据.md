## 管理
> 根目录生成根文件，*用户速览看板*，不可增加阅读负担
> 根目录生成根文件夹

- 根文件
	1. 目标/需求：`AGENTS.md`
	2. 目录/说明：`INDEX.md`
	3. 计划/方向：`PLAN.md`
	4. 任务/步骤：`TASK.md`
	5. 待确认/待办：`TODO.md`
	6. 指引/参考资料：`README.md`
- 根文件夹
	1. buff/ ：*用户与智能体共同使用缓冲区*，项目过程中的临时笔记、推论、补充说明，等等……
	2. diff/：*智能体专用*，项目过程中的工具、附件、脚本、图片，等等……
	3. distill/：项目理解，*会话或智能体交接使用*，举例如下
		- 本体认知：建模，术语
		- 工作流蒸馏：做了什么，怎么做的，总结
		- 沉淀经验：解读对照表
		- skill化设计方案：如何复现
		- 等等……
- 项目特有文件夹  `BASE` 
- 其他全是数据
## 输入
判断依据：`工作区外` 指定的 `时序表`
理解模型：`编辑区` 时序表阅读方式与定义
碎片化：聊天记录，数据表格，更改涉及的笔记
## 处理
- 运行过程提炼：交叉验证，口述信息+口述补充+测试数据+时序表
- 时间戳推理：弱化无关更改内容，强调有关更改内容。事件排布，疑问梳理，问题交叉验证确认
- 功率数据表格整理：查重，命名（日期+套数+工位）
- 对照关系参考：
	- 对象：工位 <-> 套数 <-> 对应 `时序表`，工位 <-> `功率数据表格` 对应数据列
	- 模型：`运行记录` 所选程序与功能 <-> `时序表` 分栏与读取区域 + `时序表阅读方式与定义`
	- 特征：`功率特征` 负载、变化规律、持续时间 <-> `时序表` 分栏、读取区域、步骤描述、参数 + `时序表阅读方式与定义`
	- 时间：`时间线` 定位 + `运行记录` 启动时间 <-> `功率数据表格` 锁定对应表格与对应时间段
	- 因果：`时间线` 排列参考，有问题 -> 更新 -> 测试数据 -> 有问题循环
- 不能认定为现实：
	- 疑问：包括 口述补充 与 更改涉及的笔记 提及，可能不是真正的 `问题` ，需要对照 `时间线` 辅助推理，判断以 `功率数据表格` 与 `时序表` 对照为准
	- 设定时间：口述补充 提及，以所选程序与功能对应 `时序表` 总时间为准
	- 设定结束：口述补充 提及，以 `功率数据表格` 数据为准
	- 异常：`功率数据表格` 对不上的地方，指引我查看实际数据，以我的解释为准
