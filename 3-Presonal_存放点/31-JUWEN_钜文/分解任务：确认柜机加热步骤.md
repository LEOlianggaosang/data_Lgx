## 漏洞推演
- [x] 温达标志位没有清零的情况？
	- 附加在每个跳步骤分支中
	- 跳步骤唯一出口
- [x] 定时加热还有最大时间跳步/加热延时/加热故障判断？
	- 加热故障判断加热步骤全都有
	- 所以所有加热都要判断最大加热时间
	- 只要设定时间小于6分钟无影响
	- 这次主要去掉了设定温度相关逻辑
- [x] 加热故障标志位没有清零的情况？
	- 第360秒正好判断加热故障
	- 最大45/初始42/设定45/实际45
	- 下个加热故障第0秒由加热故障函数清零
	- 重复进入可能性：
		1. 时间最大
		2. 故障赋值
- 判断条件等于秒数依然问题很大
## 解读
0. 最大时间是开头设定的不是更新的
1. 加热故障判断
	- 开头
		- 帮助步骤函数清零变量
		- 清零初始温度
	- 判断条件
		- 加热时间
		- 最大温度/初始温度
	- 更改内容
		- 更新最大温度
		- 加热故障标志位赋值
2. 温达跳步判断
	- 温达标志位不使用
	- 跳步唯一出口
		- 限制最大预设时间，实现`加热补偿`效果
		- 初始化变量
	- 加热故障判断
		- 触发不再加热
		- 只能满足最大时间跳步，实现`加热故障`效果
		- 除非温度意外到达
		- 通过赋值超过最大时间满足跳步条件
	- 加热延时判断
		- 加热步骤固有，满足才加热
		- 一直累加，关断清零，实现`加热延时`效果
	- 设定温度判断
		- 通过赋值超过最大时间满足跳步条件，实现`温达跳步`效果
		- 否则开加热，实现`定温加热`效果
3. 温达剩洗判断
	- 温达标志位判断，实现`温达跳步`与`温达剩洗`区别
	- 跳步双出口相同处理
		- 限制最大预设时间，实现`加热补偿`效果
		- 时间到达与温度到达双条件判断，实现`温达剩洗`效果
		- 初始化变量
	- 加热故障判断
		- 触发不再加热
		- 只能满足最大时间跳步，实现`加热故障`效果
		- 温度意外到达只能清零故障，实现`温达跳步`与`温达剩洗`区别
	- 加热延时判断
		- 加热步骤固有，满足才加热
		- 一直累加，关断清零，实现`加热延时`效果
	- 设定温度判断
		- 温度到达只关加热管，实现`温达跳步`与`温达剩洗`区别
		- 否则开加热，实现`定温加热`效果
4. 定时加热判断
	- 温达标志位不使用
	- 跳步双出口相同处理
		- 限制最大预设时间，不使用
		- 判断预设时间，，实现`定时加热`效果
		- 初始化变量
	- 无加热故障判断，实现`定温加热`与`定时加热`区别
	- 加热延时判断
		- 加热步骤固有，满足才加热
		- 一直累加，关断清零，实现`加热延时`效果
	- 无设定温度判断，实现`定温加热`与`定时加热`区别
