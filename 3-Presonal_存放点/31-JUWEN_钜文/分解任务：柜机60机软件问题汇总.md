## 问题描述：快速洗相关问题
### 记录时间
2026-08-16
### 现象
1. 最后一次热漂没进水：出现延时的机器内胆内无水
2. 由于热漂初始温度过高暴露加热故障漏洞：最后一分钟延时
3. 开门必定清除加热故障：开关门后正常结束
4. 特殊条件下开门温达剩洗步骤重新开始：偶然触发/已复现
5. 最后一步排水跳过：偶然触发/已复现
### 对应版本
`JW-XWJ-P01(M20260811_V35_ECO漂洗温度54_冷风进水_排水根据软水开).bin`
`JW-XWJ-D01(20260810_V14).bin`
### 原理解析
1. 快速洗缺失两个进水步骤
2. 实际温度离设定设定温度不足3度，到达了设定温度关加热继续洗涤，直到第六分钟判断为加热故障但因为温度已经回落无法清除
3. 忘记清除开门清加热故障的测试功能
4. 温达剩洗超过设定时间后的判断条件不合理，导致此时对洗涤泵无控制，仅遵循之前遗留的变量是开启而驱动洗涤泵，若开门会清除洗涤泵负载变量不再赋值，导致满足时基函数洗涤计时清零条件，步骤重新开始
5. 步骤结束使用步骤配时更新倒计时分钟下限时，不会清除用于正常倒计时累计的秒数
### 优先程度
无
### 处理方式
- 已处理
	1. 进水步骤修复
	2. 温度到达过后持续清除加热故障
	3. 去掉开门清加热故障
	4. 优化温达剩洗超过设定时间后的判断条件
	5. 洗涤结束条件取消倒计时归零判断（倒计时仅用于显示，最小值0:01）。

## 问题类型：加热步骤设计
### 记录时间
2026-07-25~2026-08-03
### 现象与对应版本
1. 加热步骤会跳时间：
	- 时间节点20260731之前所有版本
2. `定温加热-温达剩洗`加热不到设定温度：
	- 时间节点20260729
	- `JW-XWJ-P01(M20260729_V22).bin`
	- `JW-XWJ-D01(20260729_V12).bin`
3. `定温加热-温达剩洗`热故障后无法结束：
	- 时间节点20260730
	- `JW-XWJ-P01(M20260730_V23).bin`
	- `JW-XWJ-D01(20260729_V12).bin`
4. `定时加热`没有正常结束：
	- 时间节点20260731
	- `JW-XWJ-P01(M20260731_V24).bin`
	- `JW-XWJ-D01(20260731_V13).bin`
5. `定温加热-温达剩洗`加热补偿没有限制时间：
	- 时间节点20260731
	- `JW-XWJ-P01(M20260731_V25).bin`
	- `JW-XWJ-D01(20260731_V13).bin`
### 原理解析
1. 之前所有加热步骤都是`定温加热-温达跳步`，需要改为`定温加热-温达剩洗`。但是供应商之前`定温加热-温达剩洗`全部做成`定温加热-保温`需要进行修正
2. 用`定时加热`的功能仅增加温度判断是否打开加热管的处理，做成`定温加热-温达剩洗`只会在提前到达温度时关闭加热管继续洗涤，导致加热到设定时间温度没到步骤也直接结束
3. 为了更改上述问题，在`定时加热`与`定温加热-温达剩洗`共用步骤中的结束条件增加了除时间外的加热判断，导致`定温加热-温达剩洗`功能中出现`加热故障`后因为判断温度没有达到设定温度而不跳下一步
4. 由于`定时加热`与`定温加热-温达剩洗`功能共用同一个步骤，导致`定时加热`结束时也需要判断设定温度
5.  由于新增`定温加热-温达剩洗`步骤没有加上最大时间在不触发`加热故障`前提下，如果一直不达到设定温度，就会一直执行`温度补偿`加热不结束
### 优先程度
无
### 处理方式
- 已处理
	1. 做成单独的`定时加热`/`定温加热-温达剩洗`/`定温加热-温达跳步`三种加热步骤
	2. `定时加热`只判断设定时间是否到达，不判断温度
	3. `定温加热-温达剩洗`提前到达温度时关闭加热管继续洗涤；到设定时间温度没到设定温度触发加热补偿，最多25分钟强制跳步；加热累计6分钟温度没有上升3度进入加热故障处理，关闭加热管洗涤最大时间到25分钟强制跳步。
- 待处理
	- [x] 更新时序表，修改所有加热的参数写法
	- [x] 修正并确认目前3种加热步骤的运行逻辑
	- [x] 确认加热故障与加热延时的运行逻辑
	- 后续程序设计考虑更改实现方式

## 问题描述：倒计时时间上限问题
### 记录时间
2026-07-28
### 现象
1. `定温加热-温达跳步`步骤结束时出现跳时间现象
2. 洗涤结束前，剩余时间还有2-3分钟
### 对应版本
之前所有版本
### 原理解析
1. 当前程序倒计时只设置了时间下限
2. 当部分步骤提前结束，倒计时为正常计时，本步骤多余配时距离倒计时下限不断累计
3. 所有步骤中，只有 `定温加热-温达跳步`步骤结束前，倒计时强制更新到剩余时间下限
4. 还有剩余累计的多余时间时，洗涤到结束步骤就直接关机
5. 水温高时的`定温加热-温达跳步`步骤、水流量大时的进水步骤，无再生步骤的干燥阶段，必然会累积多余倒计时
### 优先程度
==低==
### 处理方式
- 未处理
- 待处理
	- [ ] 增加步骤时间上限判断，跳步骤时剩余时间更新至本步骤时间上限

## 问题描述：工作函数变量处理问题
### 记录时间
2026-07-25
### 现象
相关问题：加热故障误判问题
### 对应版本
所有版本
### 原理解析
1. 时基函数秒级分支每秒进入一次
2. 工作函数在主循环中每秒进入几百次
3. 当工作函数中使用了时基函数秒级分支处理的计数变量作为判断条件时，会出现满足相同条件的判断重复执行、赋值的情况
4. 如果此条件赋值的变量影响了父条件的判断，会让这一秒内的工作函数走向错误分支
5. 工作函数使用等于特定秒数作为判断条件时，容易出现刚好错过这一秒时缺失关键判断，步骤不能正常运行或结束
### 优先程度
无
### 处理方式
- 不处理
	- 后续程序设计规避

5. 实际卡时时间为开门前已经累计的当前步骤时间
### 优先程度
无
### 处理方式
- 已处理
