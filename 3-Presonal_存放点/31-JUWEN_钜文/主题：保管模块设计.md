## 设计者解构
### 代码构成
- `Save.c`
- 清晰的输入输出接口
	- 传入秒数推动进度
	- 函数内设定运行条件范围
	- 输出受控的负载驱动值
- 结构
	- 标志位组
	- 局部计数
	- 一个外部调用传入初始化扳机函数
	- 一个主循环常态调用入口函数
		- 处理初始化扳机：一次性启动
			- 加强烘干扳机
			- 变量初始化
		- 阶段性循环扳机：循环初始化
			- 循环开启扳机
			- 变量初始化
		- 传入秒级时基扳机：批量处理进程计数（限制运行条件范围）
		- **运行状态机/主逻辑**：根据进程规定不同规则与触发扳机
			- 拆解分支
				- 加强烘干
					- 冷风热风
					- 循环开启扳机
				- 循环
					- 结束：循环开启扳机/结束循环
					- 未结束
						- 静阶段
							- 动扳机
							- 变量初始化
						- 动阶段
							- 灯规则
							- PTC规则
								- 热风/扳机
								- 冷风/扳机
	- 4个外部调用输出封装内参数函数
		- 3个负载（限制运行条件范围）
		- 一个时间处理供UI调用
### 宏定义参数
- `Save.h`
- 清晰的调节参数
	- 加强烘干算不算进总时间
	- 加强烘干先开热风还是先开冷风
	- 先开的开多久/调节占比
		- Ps.可以组合成全热风
	- 加强烘干的总时间
		- Ps.可以关闭加强烘干
	- 循环数
	- 循环时间
		- Ps.可以组合成整个保管长度
	- 单循环动阶段/调节占比
		- Ps.默认动阶段热风冷风循环
		- Ps.剩余循环时间默认静阶段
	- 灯开多久
		- Ps.总是后半段开
		- Ps.可以配置成全开
	- 热风开多久
		- Ps.先开热风后开冷风
	- 冷风开多久
		- Ps.若冷热风正好填满动阶段则不会循环

### 会话内容
- 理解：是什么
	- 设备“保管/烘干保管”带时序的有限状态机，用来控制一套周期性的保管运行流程
	- 预热等待 → 进入循环 → 工作加热/通风/灯光 → 计数循环次数 → 到达结束条件关闭电源
- 粗读维度
	1. 模块职责概述：配置模版
	2. 全局标志位设计：解释标志位
	3. 关键静态计数器：解释宏定义
	4. 初始化流程
	5. 运行流程主循环
- 精读维度
	1. 整体设计
		- “状态机 + countdown 计时器”的模块
		- 模块通过这些 flag 来切换保管流程，每个阶段都向外部暴露当前状态
	2. 参数含义：周期性
	3. 核心控制流程：“PTC 加热 + 风机换气 + 断续循环”的策略
		- 初始化
		- 等待
		- 正式周期
		- 运行阶段
		- 交替控制
	4. 外部状态获取
		- 查询接口
		- 保护条件：开门/暂停/故障
	5. 时间显示逻辑返回
