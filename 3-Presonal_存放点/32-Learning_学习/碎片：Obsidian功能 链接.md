#Obsidian
## 语法
```text
[[笔记名称]]           # 基本链接
![[笔记名称]]          # 嵌入链接
[[笔记名称|显示文本]]   # 自定义显示文本
[[笔记名称#标题]]       # 链接到具体标题
[[笔记名称^块引用]]     # 链接到具体段落
```
## 特性
- 机制
	- 链接
		- 匹配标题
		- 连锁更改
		- 输入下拉
		- 存在创建
	- 反链
		- 数据库索引
		- 实时渲染
		- 上下文展示
- 编辑
	- 内部链接
		- WIKI形式
			- **嵌入**
			- 别名
			- 标题
			- 块/无特殊符号自定义编码
		- 选扩或下拉
		- 笔记内部省略名称
	- 外链
		- 描述或网址
	- 反向链接
		- 反链与出链栏
		- 出链渲染
		- **反链在标签页底部显示**
			- 链接当前文件/提到当前文件名
			- 列表显示选项：
				- 折叠为标题
				- 显示连接行
				- 显示上下文
				- 排序
				- 搜索
- 笔记重组
	- 内容转移：下拉最近文件，用双向链接替代原文
	- 章节转移：时自动识别关联命名笔记
		- 自动创建章节同名笔记
		- 同名章节链接会在重组后自动更新
			- 如本笔记省略内部链接会更新为其他笔记名章节链接
## 核心插件
- 反向链接
- 出链
- 知识图谱
- 笔记重组
## 快捷键
- 反向链接：在标签页底部/显示开关
- CTRL
	- 点击：本标签页打开
	- 光标：小窗，触发`页面预览`
- 指令：
	- 内链： `Ctrl + L`
	- 外链： `Ctrl + Alt + L`
	- 附件： `Ctrl + Shift + L`
