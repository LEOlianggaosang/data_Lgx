### HTML内容
- HTML限制
	- 净化处理：`<script>` 元素
	- HTML 内不支持 Markdown：取消渲染
	- HTML 块必须是完整的：空行打断完整性
- 常见 HTML 用法
	- 注释 `<!-- HTML Comment -->`
	- 下划线 `<u>Example</u>`
	- 段落内回车 `<br>`
	- 文本区域更改字体 
		- `<div> Example </div>`
		- `<span style="font-family: cursive">your text</span>`
	- 删除线 `<s>this</s>`
