## 参考
### 标准结构
根据官方规范，AGENTS.md 包含五个标准化 H2 标题区块： 
[AGENTS.md 规范完整指南 2026:跨厂商 AI Agent 项目记忆新标准](https://qcode.cc/agents-md-spec-complete-guide)

|Section|内容说明|
|---|---|
|**Identity**|Agent 身份、角色定位、响应语言|
|**Capabilities**|能力声明、工具偏好、模型版本|
|**Tools**|可用工具列表、权限范围、外部 API 配置|
|**Memory**|项目背景、约定、术语表、历史决策|
|**Constraints**|禁止行为、安全规则、合规要求|

- 最小示例
	```
	# AGENTS.md — 项目 AI 协作规范  
	  
	## Identity  
	- 你是本项目的 AI 开发助手，负责遵守以下规则并生成可运行代码。  
	  
	## Capabilities  
	- 熟悉 Next.js 15、TypeScript、Postgres、Prisma、Vitest。  
	  
	## Tools  
	- 可调用本地脚本：`npm run lint`、`npm run test`  
	- 禁止访问外部网络 API（除非在 Tools 中声明）  
	  
	## Memory  
	- /legacy 目录已冻结，禁止修改  
	- 所有 API 路由放在 /app/api/  
	  
	## Constraints  
	- 禁止默认导出，必须使用具名导出  
	- 提交前必须通过 lint + test
	```

### 有效内容
- 内容
	1. **技术栈**（版本必须明确）
	2. **项目约定**（目录结构、命名规范、代码风格）
	3. **权限边界**（禁止修改的目录、必须使用的工具链）
	4. **验证步骤**（lint、test、API 文档更新）
	5. **示例代码**（比抽象描述更有效）
	6. **子目录 AGENTS.md**（适配 monorepo 多 Agent 并行）
