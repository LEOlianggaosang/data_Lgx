# 1.15
## 1.15.1/2026-11-12
### 移动端
- 新增：
	- Web viewer 核心插件，
	- Android：新增了一个“查看笔记主屏幕”小部件，用于显示“笔记内容”，取代了“打开笔记”小部件
- 优化：
	- 库：
		- 显示：存储位置、文件数量、同步保险库和社区插件
		- 可以以受限模式打开
		- 更多菜单：重命名、移动和删除
		- 从屏幕边缘滑动现在会返回
	- Android：
		- 主屏幕小部件优化
		- Obsidian 在包含大型隐藏文件夹的保险库中启动得更快，例如 。`.git`
		- 删除提示现在显示文件会被放到已经去过的文件夹
	- 更改
		- 滑动侧边栏
		- 设置和社区插件视图
### 桌面端
- 新增：相关性排序选项
- 优化：
	- 搜索
	- 性能
	- 编辑：实时预览、智能列表
- 更改：
	- 网页查看器→首页和搜索引擎→设置现在在每台设备上分别设置，不再与保险库同步
	- 同步：与您共享的保险库在首次连接时不再默认同步主设置、外观、主题、片段或快捷键
	- 社区插件：安装插件时不再会读取安装前保险库自带的设置
- 修复

		- 打开笔记小部件现在显示笔记名称

		- 修改了工具栏布局。新的组菜单可在显示工具栏菜单中使用
		- 聚焦优化

	- 对单独Markdown文件的打开支持（需要重新安装）
