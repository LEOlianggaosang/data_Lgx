# 按效果分类
## Markdown
- 链接
- 文本格式：包裹
	```text
	**粗体文本**      # 加粗
	*斜体文本*        # 斜体
	~~删除线~~        # 删除线
	==高亮文本==      # 高亮（Obsidian 扩展）
	`行内代码`        # 代码
	```

- 段落格式：回车与进格
	- 有序/无序/待办
	- 文本块：控件复制
	- 缩进
- 行格式：插入
	- 引用
	- 标注
	- 代码块
	- 列表
	- 分割线

# 按输入符号分类
- 反斜杠 `\`
	- 取消符号语法/特别是行内代码代码消除不了时
- 斜杠 `/`
	- 核心插件：指令输入
- 分字符 \`
	- 代码块
	- 行内代码
- 等于号 \=
	- 高亮
	- 章节线
	- shift加号 `+`
- 脱字符 `^`
	- 块编号
	- 脚注
- 井号 `#`
- 方括号 `[]`
	- 待办
	- 链接
# 特性
## 等效性
- 无序列表 `-` `+` 等效
- 下划线等效 
	- `---` 下划线/小标题/属性
	- `/=` 小标题/数据视图插件语法
- 强调符 `*` `_` 灯效
- 待办列表只有填入 `X` 划线
	- 空置
	- 填入符号
## 控件化
- 高亮 [[示例：Obsidian高亮]]
	- 文本格式语法：==🟠新版本更新== [[碎片：Obsidian发行说明]]
		- 语法：插入表情跟随
		- 输入：补全提示下拉

		- 右键：下拉增加
			- 文本内容->文本格式->高亮
			- 默认
			- 六色
	- 控件化/实时预览时：光标重叠显示格式/单击标签选择
- 内部链接
	 - 输入时下拉选项
- 段落
	- 折叠
	- 文本块：复制
- 小标题
	- 右键：下拉增加
		- 重命名
		- 收藏/书签
		- 移动/笔记重组
- 表格 [[碎片：Obsidian功能 表格]]
