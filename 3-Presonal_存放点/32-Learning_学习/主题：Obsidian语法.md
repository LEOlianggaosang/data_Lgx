# 按效果分类
## Markdown
- 链接
- 文本格式：包裹
	```text
	**粗体文本**      # 加粗
	*斜体文本*        # 斜体
	~~删除线~~        # 删除线
	==高亮文本==      # 高亮（Obsidian 扩展）
	`行内代码`        # 代码
	```
- 段落格式：回车与进格
	- 有序/无序/待办
	- 文本块：控件复制
	- 缩进
- 行格式：插入
	- 引用
	- 标注
	- 代码块
	- 列表
	- 分割线

# 特性
## 等效性
- 无序列表 `-` `+` 等效
- 下划线等效 
	- `---` 下划线/小标题/属性
	- `=` 小标题
- 强调符 `*` `_` 灯效
- 待办列表只有填入 `X` 划线
	- 空置
	- 填入符号
## 控件化
- 内部链接
	 - 输入时下拉选项
- 段落
	- 折叠
	- 文本块：复制
- 小标题
	- 右键
		- 重命名
		- 收藏/书签
		- 移动/笔记重组
- 表格 [[碎片：Obsidian功能 表格]]
- 标注
	- 标注标题可以叠加格式增加表现力
	- 有正文属性：应用文本格式与段落格式/通常是加粗与小标题
	- 引用符的缩进特性与段落特性，嵌套特性
- 脚注
	- 控件化只有相互跳转功能
	- 渲染时会自动排序
	- 联动 `脚注列表`
	- 输入时下拉选项
