#### 智能体模式
- 智能体工作流 ^aiworkflow
	- Ask (对话模式)：专注于技术问答与概念解释，不直接修改代码。适合快速获取思路或查阅 API
	- Craft (Agent模式)：专注于当前上下文的代码生成与局部修改。响应迅速，适合精准的函数编写或小范围重构
	- Plan (计划模式)：最强自动化模式。适用于跨文件修改或复杂功能开发。AI 会先制定任务清单（Plan），经您确认后自主执行读取、修改及环境检查 [[#^plan]]
