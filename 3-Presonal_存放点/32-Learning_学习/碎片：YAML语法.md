- “让人读起来像自然文本”
## 行
- 缩进
	- 代替括号
	- 只能空格
	- 缩进量绑定层级
- 用换行代替逗号
- 大小写敏感
- 注释用 # 前要有空白（或位于行首）才生效，行内 # 属于普通字符
## 块
- `---` 开始一个文档，`...` 结束文档（可选）。
- 文件开头没有 `---` 时，内容就是一个单独文档
- 块风格与流风格
## 映射
- 冒号后必须有空格：a: b 是映射，a:b 是一个标量字符串
- 序列 Sequence（数组/列表），后可接映射
- 显式 tag，强行定义值类型
- 内容唯一
## obsidian格式
- 类型type（默认）
	- tags/标签专属
		- 出现在标签面板或搜索里
	- aliases/别名
		- 参与链接补全与搜索
	- cssclasses/CSS样式
		- 列表/支持多条规则
	- publish/发布
		- 是或否
	- permalink/发布专用
		- Publish 固定链接/文本
	- description/描述
		- Publish 沿用
	- image/cover/卡片或封面图
		- Publish 沿用
- 值类型/（默认图标）
	- 复选框
		- 布尔值
	- 日期
		- 启用日记后点击可跳到对应日记
	- 日期&时间
		- ISO 8601
	- 列表
		- 每项一行 `-`；可含文本、数字、内链（内链加引号）
	- 数字
		- 非表达式
	- 文本/单行文本
		- 内链引号 `"[[Link]]"`
- 配合模版变量语法
	- `{{date}}`、`{{time}}`、`{{title}}`
- CSS/见obsidian属性
	- 建 CSS 片段 [[碎片：CSS片段]]
	- 识别并启用
	- 元数据声明
