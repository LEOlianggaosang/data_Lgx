## 雷神龙
### 机制
- 弱龙冰爆破
- 发电器官破坏放电漂浮：灭灯机制
- 带电状态部位肉质变化，放技能带电
- 腿部鳍保护腹部，放技能或倒地暴露亮起
- 磁场变化环境工具
### 相性
- 镰鼬轻弩：
	- 贯通速射：消音器距离足够
	- 斩裂速射：破坏部位，较远处
	- 冰贯：倒地顺身体，腹部弱点暴露
- 轻弩输出：护村攻击特化与百龙榴弹不如镰鼬斩裂特化
- 迅龙贯通配装
	- 贯通2速射，长枪管，粗暴偏移
	- 双手里剑投掷贯通狗
	- 拉丝方向，反向拉丝处理紫光散射
	- 一阶段打头倒地腹
	- 发光部位：倒悬头，切换手，倒地腹，紫光扫射背部亮
	- 二阶段准时破龙，拉丝+跃跨栏回去
	- 三阶段准时击龙，站炮台抬升
	- 二三阶段地环打腹部炸膛
	- 硬头贯，海身孔，慧手弱特，蛮腰孔，金脚超会。无伤，速射
- **迅龙弓**
- **操虫棍相性**
- **双刀搓背**
- **太刀流程**
- 大剑流程攻略：
	- 开始头击倒：拔3
	- 腹部平台：113/正好平台313
	- 紫光散射肩装撞打头：3蓄激昂
	- 双手蓄力打手打断：拔3强3
	- 线地爆回走打头：拔3
- 地形炮台击杀
	- 弩9下头双虫换台地环9下手
	- 反向拉虫回跃上低台阶
	- 进怒飞扑正对弩托台30下倒地腹
	- 拉虫空中掏爆桶怼，调和，炸弹客，团子火药术
	- 地环腹部台阶双爆桶再掏大爆
	- 雷柱纵三环抬升机关弩打手
	- 雷云蓄力打手打断
	- 速射抬升蓄力打腹部打断
	- 速射低台打头，雷环打手与背
	- 击龙枪一解锁趁中央雷柱使用
	- 地环结束提前走位首次抬升大炮，8次倒最高16下
	- 二次大炮高台被拆转台
	- 狗打眠龙击炮开眠
	- 正对炮抬升点收割
### 肉质
- 贯通：头部胸部灌伤，尾巴尖，带电时可破坏部位肉质
- 斩裂：鲜艳部位与尾部破坏
- 榴弹：固伤打对应部位破坏
- 冰灌：头部，腹部肉质
### 处理
- 流程：
	- 阶梯：腹部
	- 打头倒地腹部
	- 一阶段：机关弩，头，地环手腹，倒地头。
	- 抬升雷柱：机关弩
	- 破龙炮2000+300
	- 二阶段：速射炮，头手腹，不要用扳机连发，防御
	- 击龙枪150*3*4，长射程
	- 三阶段：大炮抬升位置
	- 击龙枪后往中间走正好带到大炮平台
	- 大招大炮80+300
	- 击破雷袋1000
- 飞身跃入
### 招式
- 通用：
	- 招式：
		- 口球：
			- 倒立未灭头灯才会跟环
			- 三阶段双环
		- 侧飞口球
		- 旋转龙车：
			- 一阶段接紫激光扫射
			- 二阶段接聚能环
			- 三阶段路径竖光圈：切换体位
				- 转直立：接线状地爆
				- 转倒立：接横扫光炮+紫激光双散射
		- 横向侧咬：竖向远离
			- 二阶段接线状地爆
			- 三阶段：切换体位
				- 普通转直立：接线状地爆
				- 普通转倒立：接口球+紫光追踪
				- 愤怒：线状地爆/口球/撑地环/旋转龙车冲刺
		- 倒挂咬/二连咬：纯体术不派生
	- 愤怒：口白气
	- 雷袋光：
		- 倒地：锁血不炸膛
		- 双手撑地地环：倒立旋转/直立拍地/可跨栏过
		- 尾砸：台阶
		- 紫激光扫射
		- 紫光跟踪：双平台抬升
- 一阶段
	- 倒立体位：
		- 头光：灭灯倒地
		- 紫激光一段散射：雷袋/头部盲区
		- 单手同心圆：
			- 普通：一次接侧咬
			- 愤怒：两次接蓄力口球
		- 双手撑地地环：4梯台
		- 尾砸：雷袋前阶梯抬升
- 二阶段
	- 直立体位：
		- 手/头/尾光：双部位灭灯倒地
		- 条状地爆：易躲/长硬直张嘴
		- 甩尾：先跑远前摇
		- 双手撑地地环+扩散雷电：4速射平台/侧面射雷袋无雷柱，破龙炮出
		- 双手撑地蓄力雷云：时间长
			- 大炮坠机
			- 打手坠机
			- 中间空洞
		- 单手聚能环：长硬直/地台机关弩
		- 紫激光蓄力扫射：速射平台抬升
- 三阶段
	- 倒立轮流：
		- 手/头/尾/背/胸轮光：双部位灭灯倒地
		- 紫激光二段散射
		-  双手撑地地环+扩散雷电：4梯台
		- 单手4同心圆+紫光跟踪：双平台抬升，击龙枪出
		- 扇形地爆：扇尖盲区
			- 接紫激光二段散射
			- 接尾砸：雷袋前阶梯抬升
		- 双手同心圆
			- 接紫激光二段散射
		- 六球环：侧边/大硬直
		- 横扫光炮：俩地台挡/机关弩
	- 直立轮流：
		- 手/头/尾/背/胸轮光：双部位灭灯倒地
		-  双手撑地地环+扩散雷电+垂直雷环：4速射平台/雷环波及防御
			- 接条状地爆
		- 双手撑地蓄力雷云：时间长
			- 大炮坠机
			- 打手坠机
			- 中间空洞
		- 单手聚能环：长硬直
		- 紫激光蓄力扫射：空中垂直同心圆：速射平台抬升/波及防御
	- 粗紫激光环射：蓄力大招
		- 进三阶段必出一次/时间长再出
		- 高低平台炮台打坠机
		- 遮挡平台底下躲环射
		- 高低平台炮台躲核爆
