# 使用策略
## 策略
- 工具越多AI越笨
- 规则多反而制约了AI思考
- 工作区智能体自主整理细节
- 人设定根源约束与规则
## 库分类
### 灵感库
- 别名：个人知识库、个人库
- 主体：用户
- 职责：
	- 个人助手，收敛念头，存储灵感与歧路
	- 侧写个人思考模式，吸收与生长
	- 语料库，充当本体论解释
	- 专注个人需求与日常仓库功能
- 痛点：
	- 多端obsidian同步，git辅助，其余库主要靠git同步
- 库结构
	- 说明：主体是时间线与知识树
		- 分布式指引：根据实际使用情况再反向总结
	- *约束*：**git与ob权限限制**、**阅读顺序**
	- 元数据：直接在 `谷歌OKF` 类别上拓展
		- 按结构需求增加自定义类别
		- 只学形式，不和使用者解耦，实际沿用双链
### 知识库
- 别名：资料知识库、资料库
- 主体：智能体
- 职责：
	- 输入，整理，查询
	- 承接个人库语料指向，组织节点标记延续
	- 知识库理论代偿
	- 自生长
	- 自动化：检查并处理收件箱，联动个人库
- 痛点：
	- 体量大不适合同步，由AI处理
- 库结构
	- *约束*：使用标准理论，**结构代偿**/实验性，预设框架/设计图
	- 元数据：直接用 `谷歌OKF`
#### 歧路：WIKI库
- 理念：教学，可视化，网页化，组织知识
### 规则库
- 别名：智能体库、概念库
- 主体：智能体
- 职责
	- 通用框架工作区，协作工作区
	- 用于处理个人库与项目库
	- 提炼方法论
- 痛点
	- 效率下降，上下文污染
	- 概念互相纠缠
	- 框架管理领域
- 库结构
	- *约束*：**极简**、**职责分配**、**模块化**、**结构化**
	- 根文件设计：约束、目录、说明、计划、差异
	- `灵感库` 与 `智能体库` 区别
		- 主体：写 <-> 读
		- 时间线：日记 <-> 变更记录
		- diff：处理缓存文件夹 <-> 根文件
		- 9/90目录：panel <-> system
			- system：变更记录、会话身份卡、流程图/树状视图、模版、附件
		- inbox：灵感/本日待处理 <-> 自动化行动起点
#### 歧路：skill库
- **职责skill化**
	1. 定义：
	2. 原则：
	3. 边界：
	4. 触发
		- 联动触发：
		- 职责触发
		- 单指令显式触发：
		- 有内容显式触发：
#### 歧路：自主人格库
- 理念：自主执行，个体化，养鱼，记忆星图
### 项目库
- 别名：文件夹库、会话会话库
- 主体：智能体
- 职责：
	- 独立工作区，处理独立任务
	- 从灵感库获取语料，其他项目库获取对应经验
	- 沉淀工作流与方法论，构建项目模型
	- 跟随会话，注重成成果，实际输出项目
- 痛点
	- 待收敛工作区与会话
		- Copilot-lgx
		- DSH-lgx
		- WB-lgx
	- 内存占用
- 库结构
	- *约束*：项目库设计图，wb试点
	- 未应用模版与日记功能
	- 项目库结构：直接用 `CODE+PARA`
		- 叠diff，buff，template
		- 加上特殊项目对应结构的处理方式
		- 组织P固化处理过程后存入A维护：格式脚本封装成skill
	- 根文件设计：约束、目录、说明、计划、任务、待办
		- 脚注批注 TODO
	- 元数据：直接用 `谷歌OKF`
#### 歧路：插件库
- 理念：专门研究可视化功能、插件、应用
	- 生成组件缓存工作区与安装包存放点
# 智能体策略
## 框架分类
- WB
	- 生态
		- 与文档处理匹配
	- 资料
		- 与知识库匹配
	- 能力
		- 微信文章处理：OK
		- 哔站视频处理：NG
			- AI字幕受限
			- 音频模型转写：无法兼顾图像与评论
- DSH
	- 插件化
		- 与项目库匹配
- copilot
	- 可用gpt
	- 优化的早/全球平台
		- 拖动上下文
		- 自定义智能体与模块化
		- 工作树、子代理
		- 会话回退与分支
## 智能体管理
- 当前列表
- 历史变更
- 组件来源/原由
- 启用情况/时间
- 功能解释与个人标注
### 通用需求
1. Harnesses/框架区别（比如copilot有画布功能，DSH有创造模式）
2. Agents/智能体（DSH的模式？WB的专家?）
3. Plugins/插件
4. Instructions/约束/指令
5. Skills/技能
6. Tools/工具
7. Hooks/钩子
8. 可用模型
9. 可用斜杠指令
10. 设置选项（用户设置和组件设置）
11. 记忆处理
## 协作
- 协同
	- 不同框架/不同会话/相同工作区
		- 相同约束
		- 记事交接
	- 不同终端
		- 会话记录不同步：必须依赖相同工作区/git
		- 环境不同步：智能体自定义
	- 相同工作区
		- 一个执行，一个审查
