# 库
## 分类
- 知识库
	- 输入，整理，查询
	- 接收采集权限
	- 使用预设框架
		- 未定框架
	- [ ] 如何自动化？
		- 目前全权限能跨库检索
- 规则库：效率下降，上下文污染
	- 通用框架工作区
- 概念库：互相纠缠
- 个人库：吸收与生长，收敛念头，歧路司
- wiki库：支持个人库，处理长体系文本
## 职责
- 灵感库：时间线与知识树
	- 个人知识库
- 智能体库：用于管理灵感库
	- 规则库
	- 协作通用工作区
- 知识库：自生长
	- 标准理论
	- wiki库
- 项目库：独立工作区
## 区分
- `灵感库` 与 `智能体库` 区别
	- 主体：写 <-> 读
	- 时间线：日记 <-> 变更记录
	- diff：处理缓存文件夹 <-> 根文件
	- 9/90目录：panel <-> system
		- system：变更记录、会话身份卡、流程图/树状视图、模版、附件
	- inbox：灵感/本日待处理 <-> 自动化行动起点
