# 关联属性
## 定位
- 每个笔记关联属性定位：
	1. 概念归属：`标签`/用途定义
	2. 活跃流向：`2-Space_工作区`/深度处理过程
	3. 存放位置：`3-Presonal_存放点`/文件夹
	4. 卡片挂靠：`4-Memory_知识库`/节点
## 示例
- `思路`前缀：
	1. 概念归属：改造知识库处理逻辑
	2. 活跃流向：`日记`灵感->思路前缀笔记
	3. 存放位置：`33-ToDo_策略`
	4. 卡片挂靠：知识库/`41B2A-Thinking_思考`
- `工作流`前缀
	1. 概念归属：处理实际事务
	2. 活跃流向：`日记`进度->工作流前缀
	3. 存放位置：`31-JUWEN_钜文`
	4. 卡片挂靠：时间线/`月记`
- `待办`前缀
	1. 概念归属：分析后续探索策略/改变现状
	2. 活跃流向：`日记`汇总->待办前缀
	3. 存放位置：`33-ToDo_策略`
	4. 卡片挂靠：知识库/`41B2B-ToDo_策略`/分支四条尝试路线
## 计划
- 计划思路完成后规则应用于`0文件夹`
- 按此格式补全其他前缀定位
# 工作区衍生
## 定义
- 用途定义
	- 分散信息聚合
	- 可恢复性
- 类型1：当前伪工作区依附
	- 日记
	- 工作流
	- 待办引申
	- 主题引申
- 类型2：`2-Space_工作区`存档
	- `工作流`前缀增加`工作区`一级标题
	- 保留处理时工作区文件活跃状态
	- 重新定义为针对某件事日期切片，归属时间线
	- 同名备忘工作区标题：`心流`，`收藏夹`，归属时间线
- 类型3：工作区前缀
	- 脱离日期复用
	- 弥补工作流无法归属知识树，归属到具体知识树分支
## 计划
- 计划思路完成后规则应用于`0文件夹`
- 根据目前需求优先存档工作区
- 从 `2-Space_工作区` 直观看出当前行动方向
# 收藏应用
## 定义
- [[#工作区衍生]] 的实用性补强
- 优点
	- 完美实现工作区功能/超高实用性
	- 无需要求固定路径，与链接相同/登记笔记本身
- 缺点
	- 无法被当成事件链接到时间线/月记
	- 快捷方式/目的实现删除
## 特性
- obsidian功能
	- 知识补充
- 原生插件
	- 并列：文件/搜索/收藏
	- 移动端总览：标签树/属性表
	- PC端：移动左右侧边
		- 右侧边保持：反向链接/出链/大纲/属性添加
- 快捷键
	- 收藏：添加书签
		- 名称/路径，别名设置/默认原名，选择标签组
		- 备注：编辑书签/移除
	- 收藏当前块：块编码自定义
		- 名称/路径，别名设置/默认原名，选择标签组
		- 备注：会打开载体标签页，但不等同于标签页书签
	- 收藏当前章节
		- 名称/路径，别名设置/默认原名，选择标签组
		- 备注：会打开载体标签页，但不等同于标签页书签
	- 收藏当前搜索
		- **查询表达式**，别名设置/默认原名，选择标签组
		- 备注：跳转到搜索栏
	- 收藏当前标签页
		- 别名设置/**默认当前时间**
		- 备注：直接保存工作区所有标签页/原名
> [!NOTE] 收藏相关快捷键
> - 书签：收藏 `Ctrl + M`
> - 书签：收藏当前块 `Ctrl + Shift + M`
> - 书签：收藏当前章节 `Ctrl + Alt + M`
> - 书签：收藏当前搜索 `Alt + M`
> - 书签：收藏当前所有标签页 `Shift + Alt + M`
> - 书签：取消当前标签页书签 `Ctrl + Shift + Alt + M`
> - 书签：打开书签栏 `F6`
## 注意事项
> - 收藏的实际对象[^1]：笔记的标签页
> 	- 书签栏支持收藏对象复数存在
> 	- 设置别名/收藏块/收藏标题
> 	- 光标所在笔记会同时锁定在书签栏的分布
> 	- 笔记名称有路径显示，更改位置不会失效路径同步更改
> - 同名共存
> 	- 但从编辑区笔记标签页[^2]打开的是当前书签编辑
> 	- 更改的是已有的标签设置，不能新增标签
> 	- 只有在书签栏右键收藏当前标签页才能新增标签
> - 收藏所有标签页
> 	- 算是新建一个书签组/同时也是收藏对象
> 	- 书签组可以在书签栏中嵌套
> 	- 书签栏中可随意拖动收藏对象进行树嵌套
> 	- 收藏时/新标签打开时/取消收藏时，同名笔记收藏会产生冲突
> 	- 差异化： `收藏所有标签页` 书签组中笔记保持原名，代表工作区本身
> - 实现工作区恢复功能
> 	- 快速关闭标签页快捷键配合清空工作区
> 	- 在新标签页打开本书签组：
> 		- 新标签页：只会在选定标签页组打开本书签组
> 		- 本书签组：不包括嵌套书签组
## 计划
- 补强：复刻当前 `工作区衍生` 笔记
- 工作区只放 `工作区衍生` 笔记，作为延伸与存档，无需移动文件
- 临时标签：未完成状态协助/跨笔记待办

[^1]: 除了 `收藏当前搜索` 跳转到检索栏：实际对象是检索条件

[^2]: 包括对标签页右键，编辑区更多选项，快捷键收藏
