# 定义
- 目的：
	- 聚合
		- 加强认知
		- 书签入口
	- 存档
		- 联想存档
		- 查询存档，恢复掌控
	- 缓存
		- 心得体会，有所收获
		- 灵感延伸
		- 满足思考，整理思路
- 一种中间态笔记
	- 归属：时间线衍生/时间线之瘤
	- 指代：`工作区`，`流`，对中间态笔记的统称
	- 前缀：`工作流`/`心流`/`收藏夹`
# 定位
- 存在形式
	- 在 `日记`断点生成一份 `流`笔记，锚定在 `2-Space_工作区`中
	- 活跃性： `2-Space_工作区`只放进行中的 `流`
	- 时效性：在 `日记`留痕并链接于月记，本体归档于 `已闭环`
- 赋予书签功能意义
	- 进行中的同步存档为书签
	- `工作区`失效后删除书签
	- 针对单件事情的便捷性入口
# 格式
- `流`前缀增加`工作区`一级标题
	- 保留处理时编辑区文件活跃状态
	- 针对某件事日期切片
- `流`前缀增加`处理区`一级标题
	- 缓存处理过程
	- 吸收后可只留工作区
- 区分`标签页`
	- `工作区`字段专用于 `流`的统称
	- 固定打开标签页不再使用工作区前缀，改为 `标签页`
	- 脱离日期复用
	- 弥补工作流无法归属知识树，归属到具体知识树分支
# 工作区
- 时间线衍生：挂靠到时间线的笔记，记录关联活跃笔记的链接
- 书签组入口：单标签页快速定位切换工作区对象
- 工作区布局：记录还原编辑区标签页打开情况
