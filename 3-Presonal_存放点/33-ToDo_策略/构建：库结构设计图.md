# 骨架
- 骨架：放弃根文件体系，改为 **简短** 的大说明和分布式小说明
	- 文件夹结构：最多三层/根/X/XY
		- 说明允许先空，根据实际使用情况总结与更新，代替 `0文件夹：...`
	- 大说明/根/README：时间线与知识树，库使用方式，小说明入口
	- 说明/X/`Instructions.md`：
		- 分区原因：这部分库结构用来干嘛的，应该长什么样子
	- 小说明/XY/`instructions.md`：
		- 这部分库结构用来干嘛的，应该长什么样子，代替 `0文件夹：...`
		- 语义表
	- 文件夹占位：固定使用`.gitkeep`，与说明解耦
- 约束/AGENTS
	- 你是我思维的延伸，也是辅助我统筹一切行动的智脑，我才是本库的实际管理者，以下事项需要知悉
	- 由于obsidian库本体多端实时同步，当确认为本体时，未经允许不得擅自更改笔记内容
	- 我会在git定期上传快照作为历史记录，同时需要用git查看本次变更内容，未经允许不得擅自提交
