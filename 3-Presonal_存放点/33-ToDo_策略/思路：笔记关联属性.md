# 新
## 定义
- 思路完善后应用于`分布式约束`
- 按此格式补全其他前缀定位
## 定位
- 每个笔记关联属性定位：考虑是否应用元属性
	1. 概念归属：
		- `标签`/用途定义
		- 前缀/分布式约束
	2. 活跃/知识流动规则
		- `2-Space_工作区`/深度处理过程
	3. 存放位置：除非归档不再挪动
		- `3-Presonal_存放点`/文件夹
	4. 挂靠/整体串联
		- `4-Memory_知识库`/卡片节点
		- 时间线
## 示例
- `思路`前缀：
	1. 概念归属：改造知识库处理逻辑
	2. 活跃流向：`日记`灵感->思路前缀笔记
	3. 存放位置：`33-ToDo_策略`
	4. 卡片挂靠：知识库/`41B2A-Thinking_思考`
- `工作流`前缀
	1. 概念归属：处理实际事务
	2. 活跃流向：`日记`进度->工作流前缀
	3. 存放位置：`31-JUWEN_钜文`
	4. 卡片挂靠：时间线/`月记`
- `待办`前缀
	1. 概念归属：分析后续探索策略/改变现状
	2. 活跃流向：`日记`汇总->待办前缀
	3. 存放位置：`33-ToDo_策略`
	4. 卡片挂靠：知识库/`41B2B-ToDo_策略`/分支四条尝试路线
