# 设计图
## 规则
> 知识树命名/生长/编码规则
- 交替原则
	- 数字为边，字母为节点，逐层交替；
	- 父是节点子必为边，父是边子必为节点
	- 中心例外
- 边：`数字` 代表与上一层级的关系，必须有英文名与关系描述
	- 没有 Hook 章节
	- 卡片都保留 Description，边的 Description 写关系内容
- 中心：概念本体，标签所在，`数字0`
	- 中心是特殊的边，允许有 Hook 章节
	- 后面只能跟随非零边，只能由节点派生
	- 首段是特殊的中心：`4` 为知识库文件夹；`40` 为根/中心/第一篇笔记
	- 中心不可并列，中心不占层号
- 节点：`字母` 代表类，按关系排列
	- Link 章节只连树卡，代表向后分支节点
	- Hook 章节挂载正文（主题/专题/碎片/分解任务），正文文件不入树
- 命名格式：`编号-英文名_中文名`
- 原则：有需要就重构，编号有误直接改
- *临时处理*
	- 生长：先容纳现有卡片，按分类关系补全边；日记内容后面再整理，允许空置节点与边
	- 时间线不再作为卡片链接知识树
	- 元数据：way/level 弃用，先不管，以后重新设计
	- 推演：区分于现有，重排 + 重新命名

## 使用说明
> 以下由插件选择导出更新
- **打开 / 关闭**
	- 右侧边栏标签「知识树设计图」；每个会话首次自动打开一次。
	- 关掉后：点侧栏「+」→ 引导卡片「知识树设计图」（副标题“编辑编号、名称与父子关系”）可再打开。
	- 页面是常驻插件，可在「插件」页启用/禁用/移除。
- **界面**
	- 树是**可展开的平铺行列表**：每行有展开三角、`≡` 拖动柄、编号 + 英文名 + 中文名，行尾标角色（根·中心 / 中心 / 边 / 节点）。
	- 顶部：展开全部、收起全部、重置。底部提示规则；页脚显示状态：初始设计图 / 已暂存到本机 / 已恢复初始设计图 / 本机暂存不可用。
- **操作**
	1. **改顺序或父级**：拖 `≡`，落在某行上/下边缘=同级换位，落中间=成为该行子节点；拖进自己子树、拖根会被拒绝。
	2. **改名**：选中行后，检查器改「英文名」「中文名」（编号只读）。
	3. **新增**：选中父行 → 新增子节点，子级是边还是节点由交替规则决定。
	4. **微调**：上移 / 下移，只在同级内调整；中心 `0` 恒定排最前。
	5. **重置**：丢弃本机草稿、恢复初始设计图（按钮提示会说明后果）。
	6. **编号**：始终按位置重算——`40` 根、`41–46` 领域、数字=边／字母=节点逐层交替、`0`=中心；初始图有六个中心（`40`、`41A0`、`41B1A0`、`41B1B0`、`41B1C0`、`41B1D0`）。
- **保存与限制**
	- 编辑自动暂存在本机浏览器（换会话、刷新都保留），**不写回工作区、不进会话记录**；同一浏览器只有一份草稿，不是每个会话一份。
	- 想落成笔记还得手动对照，或另做一个导出步骤；页面本身没有缩放和图形化画布，长树靠展开/收起看。
