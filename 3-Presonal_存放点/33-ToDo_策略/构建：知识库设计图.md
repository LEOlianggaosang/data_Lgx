## copilot使用过程
> 侧写
- 获取github项目
	- 研究OKF项目：
		- 说明README：保存，做一份翻译
		- 更新SPEC：保存，做一份翻译
		- 包：下载，分析
		- 配套技能：下载并安装，解释使用方式
		- 刚开始保存整个项目？解构，带有git？
- 认知自主组织模型
	- 区域+初项目纳入
	- 总表+模版
- 初始化git库与obsidian库，应用okf管理
	- 多包管理：主学习包
	- 解释：
		- git 版本管理
		- obsidian 阅读编辑
		- okf 文档规范，解构明确
		- copilot 后续整理规则
	- 疑问
		- 如何管理？现在有什么？示意图？
		- 调用了什么工具？
	- 过程
		- 已完成任务钩子
		- 可交互可视化：生成与更新py脚本，html数据快照
- 现状库管理灵感
	- **认知专区**
	- **会话轮次追溯**
	- **可视化交互**：专注于组织方式
		- 项目地图：工作区里有什么，怎么管理
		- 思维模型：认知方式于当前工作区关系
		- 行动分支：定位当前在做什么，属于什么部分的延伸
