## Description
- 思路
	1. 选择主攻的武器。
	2. 分析武器相性技能。
	3. 确定提供技能的珠子和装备。
	4. 刷取制作对应珠子装备的素材。
	5. 针对素材产出怪物的攻略。
	6. 对武器开发配装提升刷取效率。
	7. 幕间刷新随从和护护石。
	8. 开发其他武器和特化百龙武器。
- 流程
	1. 熟悉武器。
	2. 解锁技能。
	3. 熟悉怪物。
	4. 开发配装。
	5. 改变套路。
	6. 挑选随机。
