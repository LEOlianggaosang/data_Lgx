## Description
前端开发是创建 Web 页面或 App 等界面并呈现给用户的过程
- 核心技术
	- **HTML**：构建页面结构，是网页的骨架
	- **CSS**：负责页面样式与布局
	- **JavaScript**：实现动态交互、事件处理、与后端通信
- 主流前端框架
	- Vue.js：语法友好、上手快，国内社区活跃。 
	- React：由 Meta 推出，组件化与虚拟 DOM 是核心特点。 
	- Angular：Google 推出的完整框架，适合大型项目。 
- 前端工程化
	- 包括模块化、**包管理**（npm、pnpm）、构建工具（Webpack、Vite）、代码规范（ESLint、Prettier）等，是现代前端必备技能。
