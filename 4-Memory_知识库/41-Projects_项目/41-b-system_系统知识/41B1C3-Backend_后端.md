## Description
后端是网站或应用的服务器端部分
- 核心职责
	1. 业务逻辑实现：处理前端请求、执行计算、完成核心业务流程。 
	2. 数据管理：与数据库交互，进行数据的存储、查询、更新和删除。 
	3. API开发与接口设计：为前端提供可调用的接口（REST、GraphQL、RPC 等）。 
	4. 系统架构与安全：设计系统结构、权限控制、认证、加密等。 
	5. 性能优化与维护：提升响应速度、扩展能力、稳定性。 
- 技术栈
	- 编程语言：ava、Python、Go、PHP、C 。
	- 框架：Spring Boot（Java）、Django/Flask（Python）、Express（Node.js） 
	- 数据库：关系型（MySQL、PostgreSQL、Oracle），非关系型（MongoDB、Redis）
