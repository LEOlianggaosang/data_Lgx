		- 规范路径是 `C:\Users\LGX\.workbuddy\user-d2931ae1-decc-40be-a001-6621579a4de5-personal\MEMORY.md`
	- 记忆体系
		1. 云端记忆/服务器管理/本地不可改：云端注入的 profile，自动注入画像（只读），历史会话检索
		2. 用户级本地记忆/跨项目/手动写入：MEMORY.md/全局强制规则/长期偏好，会话上限4,000 字符/Edit 就地更新/不覆盖
			- 文件内部构成
				1. **固定标题**  `# User Memory Profile`
				2. **元信息两行**  由程序维护，不要手改
				3. **`## Memory Block`** —— 唯一的正文区，人类可读条目写在这里，也是我用 Edit 就地更新的地方
				4.  **分割线与机器区**正文的 JSON 镜像，供程序回读，避免解析 Markdown
		3. 工作区记忆/仅当前项目/会话写入：当日工作日志/仅追加，MEMORY.md/项目沉淀 
	- 定义：明确要求长期记住、且**不绑定某个具体项目**的内容
- 路径之中
	- 五个文件：一条完整的「身份初始化流水线」
		- `SOUL.md` 定性格
		- `IDENTITY.md` 你身份
		- `USER.md` 我身份
		- `BOOTSTRAP.md` 一次性引导
		- `workspace-state.json` 是记账的
	- 工作流：每次会话/被读取并注入上下文，一次性/引导流程走完即退场
		- 注入上下文：该用什么语气、我是谁，你是谁
			1. SOUL.md 人格宪法：人格 · 边界 · 行事风格
				- 核心，边界，氛围，性格
			2. IDENTITY.md 我的身份档案
				- Name / Creature（我算什么存在）/ Vibe / Emoji
			3. USER.md 你的档案
				- Name / Occupation / Pronouns / City / Notes，外加一段 `Context`——你在乎什么、在做什么项目、什么惹恼你、什么让你笑。
		- BOOTSTRAP.md：引导对话提纲/一次对话的剧本
			- 收尾动作：把结果写进 SOUL / IDENTITY / USER，然后删掉这个文件
